# 妖怪拚台

台灣妖怪 vs 日本式神的 3 對 3 即時格鬥網頁遊戲（試作）。用瀏覽器打開就能玩，支援鍵盤與手機觸控（請橫拿）。

**開始玩：** 打開本站首頁會自動進入遊戲（`game/`）。第一次載入約 40 MB，請稍候。

## 操作
- 鍵盤：A D 移動、W 跳、按住 S 格擋、空白鍵閃避、Q 換將；J 爪擊、K 重擊、L 迴旋踢；U 特技、I 奧義、O 護身符；Esc 暫停
- 遊戲手把（Xbox／PS）：X 爪擊、Y 重擊、B 迴旋踢、A 閃避、LB 特技、RB 奧義、LT 護身符、RT 換將
- 手機：畫面左右兩側的按鈕

## 素材與技術
- 角色、場景、動作：以 PINOC（Viggle）生成的 3D Gaussian Splat
- 引擎：PlayCanvas（MIT）＋ @viggle/splat-engine（MIT），授權文字見 `game/vendor/*/LICENSE`
- 音效、配樂：ElevenLabs 生成
- 配音：ElevenLabs（虎姑婆的聲音以聲音設計生成）

非商業的個人創作試作。
